Сюда нужно положить 5 скриншотов из инструкции по смене региона App Store
(используются в /setup.html → раздел «Смена региона App Store»).

Ожидаемые имена файлов:
  01-account.png           экран «Учётная запись» с пунктом «Страна или регион»
  02-account-purchases.png профиль Apple ID с разделами «Покупки» / «Подписки»
  03-appstore-today.png    главная App Store «Сегодня»
  04-country-form.png      форма ввода адреса/способа оплаты при смене страны
  05-terms.png             экран «Положения и условия» (на турецком)

Допускаются и .jpg/.webp — в этом случае поправьте src в setup.html.
